# Videos

Narrated recordings of the studio and the runtime, each with an `.srt` subtitle file beside it. How they are made and how to
record them again: `studio/demo/README.md`.

| Video | Length | What it shows |
| --- | --- | --- |

| `3-north-star.mp4` | 13 min 58 s | The north star, tenet by tenet, on one architecture diagram: ISO 20022 native (the studio's dictionary, then a live PostgreSQL store's tables, a salary file and its facts); the platform workflow and the scheme leg; one workflow exported for and run on Temporal, DTFx, Elsa and Flowable; SQL Server and PostgreSQL; insert-only, versioned and hot update (hash-chained facts, an update refused, two distributions side by side, dated values, the outbox); a bank as configuration with consent; no-code and code; files, ports and events; authentication and personas; one bank per runtime |
| `02-build-a-scheme-from-scratch.mp4` | 4 min 38 s | The synthetic scheme `uae.demo` built in the studio, paid end to end, deployed on DTFx |
