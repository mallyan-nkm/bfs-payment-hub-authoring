# CLAUDE.md

This repository holds the TransactHub Designer Studio: its specification in `spec/` and the studio itself in `studio/`.

- Read `spec/CLAUDE.md` first, every session. Its guard-rails, writing rules and common Definition of Done apply to all work here.
- Do not change anything under `spec/` except in the same change as code that needs it, with a requirement id and a check, as `spec/CLAUDE.md` says. Files whose first line says `Generated by` are not edited by hand.
- Where the spec is silent or contradicts itself, add an Issue and a Recommendation to `docs/ISSUES.md` rather than inventing an answer.
- The studio's stack is recorded in `docs/adr/0001-studio-stack.md`.

## Commands

```
cd studio && npm install
cd studio && npm test                 # the automated suite
cd studio && npm run studio -- test   # factory and bank tests on the studio interpreter
cd studio && npm run studio -- kit    # the conformance kit
cd studio && npm run studio -- check  # schemas and static checks
cd studio && npm run web:build && npm start   # the studio on http://localhost:4317
cd spec && python3 tools/validate.py && python3 tools/mutation_tests.py   # the spec's own checks
```
